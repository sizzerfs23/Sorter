# File Sorter 

```
Мой первый github проект
```

```
Программа сортирует файлы по папкам, поддерживает ручное указывание названий папок и расширений файлов через код.
```
---
## Основа

```
За основу взят std::filesystem , 
использован pair с парами - расширение / имя папки,
если папки не существует, создаст свою.
```

---

## Использование 

```
./main sort directory
```

```
Где - file (имя исполняемого файла)
sort - коммандер для сортировки
directory - директория, где требуется расфасовать файлы
```

---

## Поддержка форматов

```
Хоть вы можете указывать свой формат в главном файле, по умолчанию в списке есть форматы:

.jpg  .sh
.png  .zip
.mp3  .deb (опционально)
.mp4  .torrent
.txt
.pdf
```
